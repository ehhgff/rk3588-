# 扩展版中文医学术语库

## 概述

`medical_terminology_extended.py` 是基于 ICD-10 标准的中文医学术语库，包含症状、疾病、药物、检查等分类，支持关键词匹配、意图识别、科室分类和反义词检测。

## 设计目标

```
用户输入: "我最近头痛，血压有点高"
         ↓
    ┌────────────────┐
    │  术语库匹配    │
    └────────────────┘
         ↓
    识别结果:
    - 症状: 头痛
    - 疾病: 高血压
    - 科室: 内科/神经内科
    - 反义词检查: 无冲突
```

### 6. 使用示例

```python
from medical_terminology_extended import MedicalTerminologyExtended

term = MedicalTerminologyExtended()

# 检查症状是否在术语库
def is_symptom(text):
    for category in [term.GENERAL_SYMPTOMS, term.RESPIRATORY_SYMPTOMS, 
                     term.DIGESTIVE_SYMPTOMS, term.NEUROLOGICAL_SYMPTOMS]:
        for main_term, synonyms in category.items():
            if text in synonyms or text == main_term:
                return main_term
    return None

# 查找同义词
def find_synonyms(term_name):
    for category in [term.GENERAL_SYMPTOMS, term.RESPIRATORY_SYMPTOMS]:
        if term_name in category:
            return category[term_name]
    return []

# 示例
print(is_symptom('头疼'))  # 输出: 头痛
print(find_synonyms('发热'))  # 输出: ['发烧', '发热', '体温高', ...]
```

## 应用场景

1. **关键词匹配**：识别用户输入中的医学术语
2. **意图识别**：判断用户查询的疾病类型
3. **科室分类**：推荐就诊科室

5. **反义词检测**：避免混淆相反概念
