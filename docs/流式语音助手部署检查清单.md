## 🔒 生产环境配置

### systemd服务文件
```ini
# /etc/systemd/system/voice-assistant.service
[Unit]
Description=Voice Assistant Service
After=network.target

[Service]
Type=simple
User=voice
Group=audio
WorkingDirectory=/userdata/voice_assistant
ExecStart=/usr/bin/python3 /userdata/voice_assistant/streaming_voice_assistant_deploy.py --config /etc/voice_assistant/config.yaml
Restart=always
RestartSec=5

# 资源限制
LimitMEMLOCK=infinity
LimitRTPRIO=99

[Install]
WantedBy=multi-user.target
```

### 启动服务
```bash
sudo systemctl daemon-reload
sudo systemctl enable voice-assistant
sudo systemctl start voice-assistant
sudo systemctl status voice-assistant
```
