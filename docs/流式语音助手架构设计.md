# 流式语音助手架构设计

## 核心流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  VAD 录音   │────→│  ASR 识别   │────→│  LLM 生成   │────→│  TTS 合成   │
│  (实时)     │     │  (流式)     │     │  (流式)     │     │  (句子级)   │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
       │                   │                   │                   │
       ↓                   ↓                   ↓                   ↓
  检测人声            实时转文字          按token生成        按句子合成
  1秒静音停止         增量返回            遇到标点合成       流式播放
```

## 关键技术点

### 1. VAD 录音 → ASR（已有）
- 使用 TEN VAD / WebRTC VAD
- 1秒静音自动停止
- 输出：音频文件

### 2. ASR → LLM（已有）
- 使用现有 ASR 服务
- 输出：识别文本

### 3. LLM 流式生成（需要修改）
```python
# 当前：一次性返回完整文本
response = llm.generate(prompt)  # 等待2.5秒

# 目标：流式返回，按字/词
for token in llm.generate_stream(prompt):  # 首字<500ms
    yield token
```

### 4. 句子级 TTS 合成（核心创新）
```python
# LLM 流式生成文本
buffer = ""
for token in llm_stream:
    buffer += token
    
    # 遇到句子结束符
    if token in ['。', '！', '？', '\n'] and len(buffer) > 5:
        # 立即合成这句话
        audio = tts.synthesize(buffer)
        play(audio)  # 边生成边播放
        buffer = ""

# 处理剩余内容
if buffer:
    audio = tts.synthesize(buffer)
    play(audio)
```

## 实现步骤

### 步骤 1: 修改 LLM 服务支持流式
```python
# qwen3_llm_service.py 添加流式支持
def generate_stream(prompt, max_tokens=45):
    """流式生成"""
    for i in range(max_tokens):
        token = model.generate_next_token()
        yield token
        if token == "<|endoftext|>":
            break
```

### 步骤 2: 创建句子级 TTS 合成器
```python
class StreamingTTS:
    def __init__(self):
        self.buffer = ""
        self.sentence_end = ['。', '！', '？', '\n']
    
    def feed(self, token: str):
        """接收 LLM token"""
        self.buffer += token
        
        # 检查是否句子结束
        if token in self.sentence_end and len(self.buffer) > 5:
            self.synthesize_and_play(self.buffer)
            self.buffer = ""
    
    def synthesize_and_play(self, text: str):
        """合成并播放"""
        audio = tts_service.synthesize(text)
        play_audio(audio)
```

### 步骤 3: 整合流式管道
```python
# 主流程
audio = vad.record()  # VAD 录音
text = asr.recognize(audio)  # ASR 识别

# 流式 LLM + TTS
streaming_tts = StreamingTTS()
for token in llm.generate_stream(text):
    streaming_tts.feed(token)
```

## 优化效果

### 时间线对比

**传统方式（串行）**:
```
0.0s  开始录音
2.0s  录音完成
2.0s  ASR识别 (200ms)
2.2s  LLM生成 (2500ms) ────────────────→ 4.7s
4.7s  TTS合成 (3000ms) ───────────────────────→ 7.7s
7.7s  播放完成
```

**流式方式（并行）**:
```
0.0s  开始录音
2.0s  录音完成
2.0s  ASR识别 (200ms)
2.2s  LLM生成首字 (500ms) → TTS合成 (500ms) → 2.7s 开始播放
2.7s  边生成边播... 
5.0s  全部完成
```

### 关键收益
- **首字延迟**: 4.7s → 2.7s（减少 2秒）
- **用户感知**: 7.7s → 5.0s（减少 2.7秒）
- **体验**: 从"等待"变为"实时对话"
