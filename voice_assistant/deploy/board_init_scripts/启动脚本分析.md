# RK3588 开发板启动脚本分析

## 启动流程概览

开发板使用 **BusyBox init** 系统，启动流程如下：

```
内核启动 → /etc/inittab → /etc/init.d/rcS → 按顺序执行 S??* 脚本
```

### inittab 关键配置

```
::sysinit:/bin/mount -t proc proc /proc
::sysinit:/bin/mount -o remount,rw /
::sysinit:/bin/mkdir -p /dev/pts /dev/shm
::sysinit:/bin/mount -a
::sysinit:/bin/mkdir -p /run/lock/subsys
::sysinit:/sbin/swapon -a
::sysinit:/etc/init.d/rcS  ← 执行所有启动脚本
```

## 启动脚本详细分析

### S00 - 系统初始化阶段

| 脚本 | 功能 | 说明 |
|------|------|------|
| **S00mountall.sh** | 挂载所有分区 | 执行 `mount-helper` 挂载 /etc/fstab 中定义的分区 |

### S01 - 日志和音频初始化

| 脚本 | 功能 | 说明 |
|------|------|------|
| **S01syslogd** | 系统日志守护进程 | 启动系统日志服务，记录系统事件 |
| **S01log-guardian.sh** | 日志守护 | 保护日志系统 |
| **S01alactl** | ALSA 音频控制 | 恢复音频混音器设置（根据主机名恢复 ES8388 或 RK809 音频配置）|

### S02 - 系统配置

| 脚本 | 功能 | 说明 |
|------|------|------|
| **S02klogd** | 内核日志守护进程 | 记录内核消息 |
| **S02sysctl** | 系统内核参数 | 应用 /etc/sysctl.d/ 和 /etc/sysctl.conf 中的内核参数 |

### S05 - 文件系统优化

| 脚本 | 功能 | 说明 |
|------|------|------|
| **S05async-commit.sh** | 异步提交 | 文件系统异步提交优化 |

### S10 - 设备管理

| 脚本 | 功能 | 说明 |
|------|------|------|
| **S10udev** | 设备管理器 | 启动 udevd，动态管理 /dev 设备节点，处理热插拔事件 |

### S13 - 中断平衡

| 脚本 | 功能 | 说明 |
|------|------|------|
| **S13irqbalance** | IRQ 平衡 | 优化多核 CPU 的中断分配，提升系统性能 |

### S20 - 随机数生成器

| 脚本 | 功能 | 说明 |
|------|------|------|
| **S20urandom** | 随机数种子 | 保存和恢复随机数生成器种子，确保系统随机性 |

### S30 - 系统总线

| 脚本 | 功能 | 说明 |
|------|------|------|
| **S30dbus** | D-Bus 消息总线 | 启动系统消息总线，用于进程间通信 |
| **S30rpcbind** | RPC 绑定 | NFS 等 RPC 服务的端口映射 |

### S35-S36 - 网络和无线

| 脚本 | 功能 | 说明 |
|------|------|------|
| **S35iptables** | 防火墙规则 | 配置 IP 防火墙规则 |
| **S36wifibt-init.sh** | WiFi/BT 初始化 | 初始化瑞芯微 WiFi 和蓝牙模块 |

### S40 - 网络和媒体

| 脚本 | 功能 | 说明 |
|------|------|------|
| **S40bluetoothd** | 蓝牙守护进程 | 启动蓝牙服务 |
| **S40network** | 网络配置 | 启动网络接口（ifup -a）|
| **S40rkaiq_3A** | 瑞芯微图像质量 | 启动 ISP 3A 算法服务器（自动曝光/白平衡/对焦）|

### S45-S49 - 网络服务和显示

| 脚本 | 功能 | 说明 |
|------|------|------|
| **S45connman** | 网络管理器 | 网络连接管理服务 |
| **S49ntp** | 时间同步 | NTP 客户端，同步系统时间 |
| **S49weston** | Wayland 合成器 | 启动 Weston 显示服务器（图形界面基础）|

### S50 - 核心服务

| 脚本 | 功能 | 说明 |
|------|------|------|
| **S50nginx** | Web 服务器 | 轻量级 HTTP 服务器 |
| **S50pulseaudio** | 音频服务器 | **重要：语音助手依赖的音频服务** |
| **S50sshd** | SSH 服务器 | 远程登录服务 |
| **S50systemui** | 系统 UI | Qt 系统界面（等待 Weston 就绪后启动）|
| **S50usbdevice.sh** | USB 设备 | USB 设备配置 |

### S60-S91 - 文件共享和网络

| 脚本 | 功能 | 说明 |
|------|------|------|
| **S60nfs** | NFS 客户端 | 网络文件系统挂载 |
| **S70vsftpd** | FTP 服务器 | 文件传输服务 |
| **S80dnsmasq** | DNS/DHCP | DNS 转发和 DHCP 服务 |
| **S91smb** | Samba | Windows 文件共享服务 |

### S98 - AI 推理服务

| 脚本 | 功能 | 说明 |
|------|------|------|
| **S98rknn_server** | RKNN 服务 | **重要：启动 RKNN 推理服务器，语音助手的 AI 模型依赖此服务** |

### S99 - 最后启动阶段

| 脚本 | 功能 | 说明 |
|------|------|------|
| **S99-auto-reboot** | 自动重启 | 系统异常时自动重启功能 |
| **S99chromium-wayland.sh** | Chromium 环境 | 配置 V4L2 视频编解码节点 |
| **S99fstrim** | SSD 优化 | 定期执行 fstrim，回收未使用的块 |
| **S99input-event-daemon** | 输入事件守护 | 处理输入设备事件 |
| **S99voice-assistant** | 语音助手 | **我们的语音助手服务，在所有服务最后启动** |

## 语音助手依赖关系

语音助手服务 (`S99voice-assistant`) 依赖以下服务：

1. **S50pulseaudio** - 音频输入/输出
2. **S98rknn_server** - AI 模型推理
3. **S40network** - 网络功能（可选）
4. **S49weston** - 图形界面（如需要 UI）

启动脚本中的等待逻辑：
```bash
# 等待音频服务就绪
for i in 1 2 3 4 5; do
    if pgrep -x "pulseaudio" > /dev/null 2>&1; then
        log "音频服务已就绪"
        break
    fi
    sleep 0.5
done

# 等待 RKNN 服务就绪
for i in 1 2 3 4 5; do
    if pgrep -f "rknn_server" > /dev/null 2>&1; then
        log "RKNN 服务已就绪"
        break
    fi
    sleep 0.5
done
```

## 关键服务说明

### Weston (S49weston)
- **类型**: Wayland 合成器
- **作用**: 提供图形显示基础
- **依赖**: 需要 GPU 驱动和 DRM 支持
- **启动方式**: 后台进程

### PulseAudio (S50pulseaudio)
- **类型**: 音频服务器
- **作用**: 管理音频输入输出设备
- **配置**: PULSE_HOME=/userdata/.pulse
- **重要性**: ⭐⭐⭐⭐⭐ 语音助手核心依赖

### RKNN Server (S98rknn_server)
- **类型**: AI 推理服务
- **作用**: 提供 NPU 模型推理能力
- **启动命令**: start_rknn.sh
- **重要性**: ⭐⭐⭐⭐⭐ 语音助手核心依赖

### SystemUI (S50systemui)
- **类型**: Qt 应用程序
- **作用**: 系统图形界面
- **依赖**: Weston 显示服务器
- **启动方式**: 等待 Weston 就绪后启动

## 修改建议

如需调整语音助手启动时机：

1. **提前启动**: 将 `S99voice-assistant` 重命名为 `S98voice-assistant`（在 rknn_server 之后立即启动）
2. **延迟启动**: 保持 `S99` 前缀，或在脚本中增加 `sleep` 时间
3. **添加依赖检查**: 在脚本中增加对其他服务的检查

当前配置已是最优：在所有核心服务（包括 RKNN）就绪后最后启动。
