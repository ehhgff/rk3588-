## 🔴 严重问题

### 1. librknnrt.so 版本不匹配

**现象：**
```
rknn_init error! ret=-1
Segmentation fault
```

**原因：**
RKNN API 版本 (2.3.2) 与 NPU 驱动版本 (0.9.6) 不匹配

**解决：**
```bash
# 备份原库
adb shell "cp /usr/lib/librknnrt.so /usr/lib/librknnrt.so.backup"

# 替换为兼容版本
adb push ~/桌面/ai/rknn-toolkit2-2.3.0/rknpu2/runtime/Linux/librknn_api/aarch64/librknnrt.so /usr/lib/

# 验证
adb shell "strings /usr/lib/librknnrt.so | grep version"
```

**参考文档**: [melotts调试文档.md](./melotts调试文档.md)

---

### 2. MeloTTS 段错误 (Segmentation Fault)

**现象：**
```
Segmentation fault (core dumped)
```

**原因 1：输入索引错误**
```cpp
// 错误代码
inputs[2].index = 1;  // 应该是 2

// 正确代码
inputs[2].index = 2;
```

**解决：**
编辑 `melotts.cc` 第 340 行，将 `inputs[2].index = 1` 改为 `inputs[2].index = 2`

**原因 2：向量未初始化**
```cpp
// 错误代码
std::vector<int> attn_mask(predicted_lengths_max * x_mask_size);

// 正确代码
std::vector<int> attn_mask(predicted_lengths_max * x_mask_size, 0);
```

**解决：**
编辑 `process.cc`，初始化向量时添加 `, 0`

**原因 3：缺少词表文件**

**解决：**
```bash
adb push lexicon.txt /data/melotts_deploy/model/
adb push tokens.txt /data/melotts_deploy/model/
```

**参考文档**: [melotts调试文档.md](./melotts调试文档.md)

### 3. InternVL3-1B 缺少 libgomp.so.1

**现象：**
```
error while loading shared libraries: libgomp.so.1: cannot open shared object file
```

**解决：**
```bash
# 从交叉编译器复制
adb push /usr/aarch64-linux-gnu/lib/libgomp.so.1 /usr/lib/

# 或创建软链接
adb shell "ln -s /usr/aarch64-linux-gnu/lib/libgomp.so.1 /usr/lib/libgomp.so.1"
```

**参考文档**: [internvl3-1b部署总结.md](./internvl3-1b部署总结.md)

## 🟡 一般问题

### 4. 模型加载缓慢

**现象：**
每次运行都要重新加载模型，耗时 20-30 秒

**原因：**
模型文件大，每次都要从磁盘读取到内存

**解决（优化版）：**
```bash
# 使用优化版脚本，减少冗余输出
adb shell "/data/voice_assistant/voice_assistant_optimized.sh"
```

**长期解决：**
实现模型常驻内存服务（见 `model_service.py`）

---

### 5. 语音识别不准确

**现象：**
识别结果与预期不符

**原因：**
1. 环境噪音大
2. 音频格式不正确
3. 说话不清晰

**解决：**
```bash
# 1. 确保音频格式正确
# 要求：WAV 格式，16kHz，单声道，16bit

# 2. 检查音频
adb shell "ffprobe -i /data/zipformer/model/test.wav"

# 3. 转换音频格式
ffmpeg -i input.mp3 -ar 16000 -ac 1 -sample_fmt s16 output.wav
```

---

### 6. RAG 检索不到内容

**现象：**
RAG 返回空结果或无关内容

**原因：**
1. 知识库不包含相关内容
2. 相似度阈值过高
3. 查询方式不匹配

**解决：**
```python
# 1. 检查知识库内容
python3 /data/voice_assistant/rag_retrieve.py "测试查询"

# 2. 降低相似度阈值（编辑 rag_retrieve.py）
if score > 0.05:  # 从 0.1 改为 0.05

# 3. 添加自定义知识
编辑 rag_retrieve.py 中的 _create_default_kb() 方法
```

---

### 7. 语音合成质量差

**现象：**
合成语音不自然、有杂音

**原因：**
1. 输入文本过长
2. 包含特殊字符
3. 模型参数不合适

**解决：**
```bash
# 1. 控制文本长度（建议 < 100 字）

# 2. 清理特殊字符
text=$(echo "$text" | tr -d '[:punct:]')

# 3. 调整速度参数
./melotts_demo ... --speed 0.9
```

---

### 8. 网络连接问题

**现象：**
```
adb: device offline
adb: no devices/emulators found
```

**解决：**
```bash
# 1. 重新连接
adb kill-server
adb start-server
adb connect 192.168.100.2:5555

# 2. 检查网络
ping 192.168.100.2

# 3. 开发板上重启 adb
cd /usr/bin
./adb_kill_server
./adb_start_server
```

## 🟢 优化建议

### 9. 减少内存占用

**问题：**
同时运行多个模型，内存不足

**解决：**
```bash
# 1. 关闭不必要的服务
adb shell "systemctl stop [service_name]"

# 2. 清理缓存
adb shell "echo 3 > /proc/sys/vm/drop_caches"

# 3. 使用更小的模型
# 例如：使用 w8a8 量化版本替代 fp16
```
