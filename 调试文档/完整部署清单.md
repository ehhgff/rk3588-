# RK3588 完整部署清单

> 本文档汇总所有部署步骤，方便快速复现整个项目

---

## 📋 前置条件

### 硬件要求
- LubanCat 4 开发板 (RK3588)
- 4GB 内存 / 32GB 存储
- 网络连接 (WiFi/以太网)

### 软件要求
- Debian 11 (Buildroot)
- Python 3.8+
- ADB 工具

---

## 🚀 一键部署脚本

### 步骤 1: 环境准备

```bash
# 连接开发板
adb connect 192.168.100.2:5555

# 创建目录结构
adb shell "mkdir -p /data/{zipformer,internvl3,melotts_deploy,voice_assistant}"
adb shell "mkdir -p /data/zipformer/model"
adb shell "mkdir -p /data/melotts_deploy/model"
```

### 步骤 2: 部署 MeloTTS

```bash
# 上传程序
adb push ~/桌面/ai/MeloTTS/lubancat_ai_manual_code/example/melotts/cpp/build/melotts_demo /data/melotts_deploy/

# 上传模型
adb push ~/桌面/ai/MeloTTS/lubancat_ai_manual_code/example/melotts/model/encoder-ZH_MIX_EN.rknn /data/melotts_deploy/model/
adb push ~/桌面/ai/MeloTTS/lubancat_ai_manual_code/example/melotts/model/decoder-ZH_MIX_EN.rknn /data/melotts_deploy/model/

# 上传词表
adb push ~/桌面/ai/MeloTTS/lubancat_ai_manual_code/example/melotts/model/lexicon.txt /data/melotts_deploy/model/
adb push ~/桌面/ai/MeloTTS/lubancat_ai_manual_code/example/melotts/model/tokens.txt /data/melotts_deploy/model/

# 添加权限
adb shell "chmod +x /data/melotts_deploy/melotts_demo"

# 测试
cd /data/melotts_deploy
./melotts_demo --encoder_model_path ./model/encoder-ZH_MIX_EN.rknn --decoder_model_path ./model/decoder-ZH_MIX_EN.rknn --input_text "你好，世界" --output_filename test.wav
```

### 步骤 3: 部署 InternVL3-1B

```bash
# 上传程序
adb push ~/桌面/ai/deepseek/rknn-llm/examples/multimodal_model_demo/deploy/build/demo_text /data/internvl3/

# 上传模型
adb push ~/桌面/ai/deepseek/rknn-llm/examples/multimodal_model_demo/deploy/internvl3-1b_w8a8_rk3588.rkllm /data/internvl3/

# 添加权限
adb shell "chmod +x /data/internvl3/demo_text"

# 安装依赖
adb shell "cp /usr/aarch64-linux-gnu/lib/libgomp.so.1 /usr/lib/"

# 测试
cd /data/internvl3
echo "你好" | ./demo_text internvl3-1b_w8a8_rk3588.rkllm 128 2048
```

### 步骤 4: 部署 Zipformer

```bash
# 上传程序
adb push ~/桌面/ai/rknn_model_zoo-2.3.0/build/build_rknn_zipformer_demo_rk3588_linux_aarch64_Release/rknn_zipformer_demo /data/zipformer/

# 上传模型
adb push ~/桌面/ai/rknn_model_zoo-2.3.0/examples/zipformer/model/encoder-epoch-99-avg-1.rknn /data/zipformer/model/
adb push ~/桌面/ai/rknn_model_zoo-2.3.0/examples/zipformer/model/decoder-epoch-99-avg-1.rknn /data/zipformer/model/
adb push ~/桌面/ai/rknn_model_zoo-2.3.0/examples/zipformer/model/joiner-epoch-99-avg-1.rknn /data/zipformer/model/
adb push ~/桌面/ai/rknn_model_zoo-2.3.0/examples/zipformer/model/vocab.txt /data/zipformer/model/
adb push ~/桌面/ai/rknn_model_zoo-2.3.0/examples/zipformer/model/test.wav /data/zipformer/model/

# 添加权限
adb shell "chmod +x /data/zipformer/rknn_zipformer_demo"

# 测试
cd /data/zipformer
./rknn_zipformer_demo model/encoder-epoch-99-avg-1.rknn model/decoder-epoch-99-avg-1.rknn model/joiner-epoch-99-avg-1.rknn model/test.wav
```

### 步骤 5: 部署语音助手

```bash
# 上传脚本
adb push ~/桌面/ai/voice_assistant/voice_assistant_test.sh /data/voice_assistant/
adb push ~/桌面/ai/voice_assistant/voice_assistant_rag.sh /data/voice_assistant/
adb push ~/桌面/ai/voice_assistant/voice_assistant_optimized.sh /data/voice_assistant/
adb push ~/桌面/ai/voice_assistant/rag_retrieve.py /data/voice_assistant/

# 添加权限
adb shell "chmod +x /data/voice_assistant/*.sh"

# 测试基础版
adb shell "/data/voice_assistant/voice_assistant_test.sh"

# 测试 RAG 版
adb shell "/data/voice_assistant/voice_assistant_rag.sh"

# 测试优化版
adb shell "/data/voice_assistant/voice_assistant_optimized.sh"
```

## 🔧 环境配置

### 1. 网络配置

```bash
# 设置静态IP
adb shell "ifconfig eth0 192.168.100.2 netmask 255.255.255.0"
adb shell "route add default gw 192.168.100.1"
```

### 2. 库文件配置

```bash
# 替换 librknnrt.so
adb shell "cp /usr/lib/librknnrt.so /usr/lib/librknnrt.so.backup"
adb push ~/桌面/ai/rknn-toolkit2-2.3.0/rknpu2/runtime/Linux/librknn_api/aarch64/librknnrt.so /usr/lib/

# 安装 libgomp
adb shell "cp /usr/aarch64-linux-gnu/lib/libgomp.so.1 /usr/lib/"
```

### 3. 权限配置

```bash
# 添加执行权限
adb shell "chmod +x /data/zipformer/rknn_zipformer_demo"
adb shell "chmod +x /data/internvl3/demo_text"
adb shell "chmod +x /data/melotts_deploy/melotts_demo"
adb shell "chmod +x /data/voice_assistant/*.sh"
```

## 🐛 故障排除

### 问题 1: 权限不足
```bash
# 解决
adb shell "chmod 777 /data -R"
```

### 问题 2: 库文件缺失
```bash
# 解决
adb shell "ldd /data/zipformer/rknn_zipformer_demo"  # 查看依赖
adb shell "export LD_LIBRARY_PATH=/usr/lib:$LD_LIBRARY_PATH"
```

### 问题 3: 模型加载失败
```bash
# 检查文件完整性
adb shell "ls -la /data/*/model/"
adb shell "file /data/zipformer/model/*.rknn"
```

### 问题 4: 网络不通
```bash
# 检查网络
adb shell "ping 192.168.100.1"
adb shell "ifconfig"
```

## 🔒 安全注意事项

1. **模型文件**: 包含知识产权，注意保护
2. **知识库**: 可能包含敏感信息，谨慎管理
3. **网络**: 开发板连接内网，避免暴露公网
4. **权限**: 避免使用 root 运行不必要的程序
