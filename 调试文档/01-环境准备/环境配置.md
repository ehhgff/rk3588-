# RKNN-Toolkit2 环境配置问题解决记录

## 环境信息

- **操作系统**: Ubuntu 24.04
- **Python 版本**: 3.12.13
- **Conda 环境**: `python3.12-tk2-2.3`
- **RKNN-Toolkit2 版本**: 2.3.0

---

## 问题列表及解决方案

### 问题 1: ModuleNotFoundError: No module named 'pkg_resources'

**错误信息:**
```
ModuleNotFoundError: No module named 'pkg_resources'
```

**问题原因:**
`setuptools` 82.0.1 版本已移除 `pkg_resources` 模块

**解决方案:**
降级 `setuptools` 到 69.5.1 版本

```bash
pip install 'setuptools<70'
```

---

### 问题 2: TensorFlow 版本不兼容

**错误信息:**
```
W load_tflite: 'import tensorflow' failed! Please use the following command to reinstall it:
W load_tflite:   pip3 install 'tensorflow>=1.12.0,<=2.16.0rc0'
```

**问题原因:**
RKNN-Toolkit2 需要 TensorFlow 版本在 1.12.0 到 2.16.0rc0 之间

**解决方案:**
安装兼容版本的 TensorFlow

```bash
# 先卸载现有版本
pip uninstall tensorflow-cpu -y

# 安装兼容版本（使用清华镜像加速）
pip install 'tensorflow>=2.0,<=2.16.0rc0' -i https://pypi.tuna.tsinghua.edu.cn/simple
```

---

### 问题 3: ml_dtypes 版本冲突

**错误信息:**
```
AttributeError: module 'ml_dtypes' has no attribute 'float4_e2m1fn'. Did you mean: 'float8_e4m3fn'?
```

**问题原因:**
`onnx` 需要 `ml_dtypes>=0.5.0`，但 TensorFlow 2.16.0rc0 需要 `ml_dtypes~=0.3.1`

**解决方案:**
升级 `ml_dtypes` 到 0.5.4（优先满足 onnx 的要求）

```bash
pip install 'ml_dtypes>=0.5.0'
```

**注意:** 虽然会有 TensorFlow 的兼容性警告，但 rknn-toolkit2 可以正常工作

---

### 问题 4: onnx mapping 属性错误

**错误信息:**
```
AttributeError: module 'onnx' has no attribute 'mapping'
```

**问题原因:**
onnx 1.20+ 版本已移除 `mapping` 属性，rknn-toolkit2 需要旧版本 onnx

**解决方案:**
降级 onnx 到 1.16.0 版本

```bash
# 使用预编译的 wheel 安装（Python 3.12 支持）
pip install onnx==1.16.0 -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**注意:** onnx 1.15.0 没有 Python 3.12 的预编译包，因此选择 1.16.0

---

### 问题 5: protobuf 版本冲突

**错误信息:**
```
rknn-toolkit2 2.3.0 requires protobuf<=4.25.4,>=4.21.6
```

**解决方案:**
安装兼容版本的 protobuf

```bash
pip install 'protobuf<=4.25.4,>=4.21.6'
```

## 完整环境配置步骤

### 1. 创建并激活 Conda 环境

```bash
conda create -n python3.12-tk2-2.3 python=3.12
conda activate python3.12-tk2-2.3
```

### 2. 安装 rknn-toolkit2

```bash
pip install rknn-toolkit2==2.3.0
```

### 3. 安装依赖包（按顺序）

```bash
# 1. 安装 setuptools（降级）
pip install 'setuptools<70'

# 2. 安装 TensorFlow
pip install 'tensorflow>=2.0,<=2.16.0rc0' -i https://pypi.tuna.tsinghua.edu.cn/simple

# 3. 安装 protobuf
pip install 'protobuf<=4.25.4,>=4.21.6'

# 4. 安装 ml_dtypes（升级）
pip install 'ml_dtypes>=0.5.0'

# 5. 安装 onnx（降级）
pip install onnx==1.16.0 -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 4. 验证安装

```bash
cd ~/桌面/ai/rknn-toolkit2-2.3.0/rknn-toolkit2/examples/tflite/mobilenet_v1
python test.py
```

## 常见问题排查

### Q: 安装 onnx 时编译失败
**A:** Python 3.12 没有 onnx 1.15.0 的预编译包，请使用 onnx 1.16.0 或更高版本

### Q: TensorFlow 和 ml_dtypes 版本冲突
**A:** 优先满足 onnx 的要求（ml_dtypes>=0.5.0），TensorFlow 的警告可以忽略

### Q: 清华镜像下载失败
**A:** 可以尝试其他镜像源或官方源：
```bash
pip install <package> -i https://pypi.org/simple
```
