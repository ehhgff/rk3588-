# 模型常驻内存服务使用说明

> 通过保持 InternVL3-1B 模型常驻内存，显著减少对话理解时间
> 
> 预期效果：对话理解 13s → 2s（节省 11s 模型加载时间）

---

## 📁 文件说明

| 文件 | 说明 | 大小 |
|------|------|------|
| `model_service_daemon` | 模型常驻服务守护进程 | 73KB |
| `llm_client` | 客户端程序 | 72KB |
| `voice_assistant_daemon.sh` | 使用常驻服务的语音助手 | 6KB |

---

## 🚀 使用方法

### 步骤 1：启动模型常驻服务

在开发板上启动服务（需要保持运行）：

```bash
adb shell "/data/voice_assistant/model_service_daemon"
```

**注意：**
- 首次启动需要约 15-20 秒加载模型
- 服务启动后会一直运行，保持模型在内存中
- 不要关闭此终端，否则服务会停止

### 步骤 2：测试服务是否运行

在另一个终端测试：

```bash
# 检查服务状态
adb shell "/data/voice_assistant/llm_client ping"
# 应返回：服务运行正常

# 查看模型状态
adb shell "/data/voice_assistant/llm_client status"
# 应返回：模型状态: READY

# 测试生成
adb shell "/data/voice_assistant/llm_client generate '你好'"
# 应返回：AI 生成的回复
```

### 步骤 3：运行语音助手

```bash
# 使用模型常驻版语音助手
adb shell "/data/voice_assistant/voice_assistant_daemon.sh"
```

## 🔧 服务管理

### 后台运行服务

如果希望服务在后台运行：

```bash
adb shell "nohup /data/voice_assistant/model_service_daemon > /tmp/llm_service.log 2>&1 &"
```

### 停止服务

```bash
# 查找服务进程
adb shell "ps | grep model_service_daemon"

# 杀死进程
adb shell "kill -9 <PID>"

# 或杀死所有相关进程
adb shell "pkill -f model_service_daemon"
```

### 查看服务日志

```bash
adb shell "cat /tmp/llm_service.log"
```

## 🐛 故障排除

### 问题 1：服务启动失败

**现象：**
```
[Service] 模型加载失败: -1
```

**解决：**
- 检查模型文件是否存在：`ls -la /data/internvl3/internvl3-1b_w8a8_rk3588.rkllm`
- 检查内存是否充足：`free -h`

### 问题 2：客户端连接失败

**现象：**
```
[Client] connect failed
```

**解决：**
- 检查服务是否运行：`adb shell "ps | grep model_service_daemon"`
- 检查 socket 文件：`adb shell "ls -la /tmp/voice_assistant.sock"`

### 问题 3：生成超时

**现象：**
```
ERROR: Generation timeout
```

**解决：**
- 检查 NPU 是否正常工作
- 重启服务

## 💡 使用建议

### 场景 1：长时间使用

如果需要连续进行多次对话：

```bash
# 1. 启动服务（保持运行）
adb shell "/data/voice_assistant/model_service_daemon"

# 2. 多次运行语音助手（每次只需 8s）
adb shell "/data/voice_assistant/voice_assistant_daemon.sh"
adb shell "/data/voice_assistant/voice_assistant_daemon.sh"
adb shell "/data/voice_assistant/voice_assistant_daemon.sh"
```

### 场景 2：单次使用

如果只需要单次对话：

```bash
# 使用超优化版（无需启动服务）
adb shell "/data/voice_assistant/voice_assistant_super.sh"
```
