## 2. 模型性能测试

### 2.1 Zipformer (语音识别)

**模型信息：**
- 大小：127.8 MB
- 量化：FP16
- 输入：WAV, 16kHz, 单声道

**测试结果：**

| 指标 | 数值 | 评价 |
|------|------|------|
| 模型加载 | 160ms | ✅ 快速 |
| 推理时间 | 970ms | ✅ 快速 |
| 音频长度 | 5.8s | - |
| **RTF** | **0.17** | ⭐⭐⭐⭐⭐ 优秀 |
| 内存占用 | ~200MB | ✅ 正常 |

**测试命令：**
```bash
cd /data/zipformer
time ./rknn_zipformer_demo model/encoder.rknn model/decoder.rknn model/joiner.rknn model/test.wav
```

**结论：**
- RTF < 0.2，实时性优秀
- 可以支持流式识别
- 内存占用合理

---

### 2.2 InternVL3-1B (对话模型)

**模型信息：**
- 大小：1.4 GB
- 量化：W8A8
- 上下文：2048 tokens

**测试结果：**

| 指标 | 数值 | 评价 |
|------|------|------|
| 模型加载 | ~1s | ✅ 可接受 |
| 生成 32 tokens | ~3s | ⭐⭐⭐ 一般 |
| 生成 64 tokens | ~6s | ⭐⭐⭐ 一般 |
| 生成 128 tokens | ~19s | ⭐⭐ 较慢 |
| 内存占用 | ~1.5GB | ⚠️ 较高 |

**测试命令：**
```bash
cd /data/internvl3
echo "你好" | time ./demo_text internvl3-1b_w8a8_rk3588.rkllm 64 2048
```

**结论：**
- 适合短文本生成（< 64 tokens）
- 内存占用较大，建议不要同时运行其他大模型
- 首次加载后有缓存，后续更快

### 2.3 MeloTTS (语音合成)

**模型信息：**
- 大小：160 MB
- 量化：FP16
- 支持：中英文混合

**测试结果：**

| 指标 | 数值 | 评价 |
|------|------|------|
| 词表加载 | 680ms | ⚠️ 较慢 |
| 模型加载 | 170ms | ✅ 快速 |
| 推理时间 | 1.7s | ✅ 快速 |
| 音频长度 | 4.5s | - |
| **RTF** | **0.38** | ⭐⭐⭐⭐ 良好 |
| 内存占用 | ~300MB | ✅ 正常 |

**测试命令：**
```bash
cd /data/melotts_deploy
time ./melotts_demo --encoder_model_path model/encoder.rknn --decoder_model_path model/decoder.rknn --input_text "你好，这是一个测试" --output_filename test.wav
```

**结论：**
- RTF < 0.5，接近实时
- 词表加载是瓶颈，可考虑预加载
- 合成质量良好

## 3. 系统集成测试

### 3.1 基础版语音助手

**流程：** ASR → LLM → TTS

**测试结果：**

| 步骤 | 耗时 | 占比 |
|------|------|------|
| 语音识别 | 1.3s | 5.5% |

| 语音合成 | 3s | 8.3% |

**瓶颈分析：**
