# 基础版语音助手系统

## 系统架构

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   麦克风    │ → │  Zipformer  │ → │ InternVL3   │ → │   MeloTTS   │
│  (录音)     │    │  (语音识别)  │    │  (对话理解)  │    │  (语音合成)  │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
                                                              ↓
                                                        ┌─────────────┐
                                                        │   扬声器    │
                                                        │  (播放)     │
                                                        └─────────────┘
```

## 数据流

1. **录音** → 输入音频 (WAV, 16kHz, 单声道)
2. **语音识别** → Zipformer → 识别文本
3. **对话理解** → InternVL3-1B → 生成回复
4. **语音合成** → MeloTTS → 输出音频
5. **播放** → 扬声器

## 部署文件

### 1. 语音助手脚本

**位置：** `/data/voice_assistant/voice_assistant.sh`

**功能：**
- 循环对话模式（默认）
- 单次对话模式（`--once` 参数）
- 自动录音、识别、理解、合成、播放

**使用方法：**
```bash
cd /data/voice_assistant
chmod +x voice_assistant.sh

# 循环对话模式
./voice_assistant.sh

# 单次对话模式
./voice_assistant.sh --once
```

### 2. 测试脚本

**位置：** `/data/voice_assistant/voice_assistant_test.sh`

**功能：**
- 使用现有音频文件测试完整流程
- 无需麦克风和扬声器
- 显示详细执行时间和结果

**使用方法：**
```bash
cd /data/voice_assistant
chmod +x voice_assistant_test.sh

# 使用默认测试音频
./voice_assistant_test.sh
```

## 性能指标

| 步骤 | 模型 | 耗时 | 说明 |
|------|------|------|------|
| 录音 | - | 5秒 | 固定录音时长 |
| 语音识别 | Zipformer | ~1秒 | RTF = 0.164 |
| 对话理解 | InternVL3-1B | ~3-5秒 | 取决于生成长度 |
| 语音合成 | MeloTTS | ~1-2秒 | 取决于文本长度 |
| **总耗时** | - | **~10-15秒** | 单次对话 |

## 优化建议

### 1. 减少延迟

- **语音识别**：使用流式识别，边说边识别
- **对话理解**：使用更小的模型或量化版本
- **语音合成**：使用流式合成，边生成边播放

### 2. 提高准确率

- **降噪**：录音前添加音频降噪处理
- **VAD**：使用语音活动检测，自动判断说话结束
- **后处理**：对识别结果进行纠错和格式化

### 3. 增强功能

- **唤醒词**：添加本地唤醒词检测（如"你好小智"）
- **多轮对话**：维护对话历史，支持上下文理解
- **技能扩展**：添加天气、音乐、智能家居等技能

## 故障排查

### 问题 1：录音失败

**现象：**
```
[ERROR] 录音失败
```

**解决：**
```bash
# 检查麦克风
arecord -l

# 安装录音工具
apt-get update
apt-get install alsa-utils

# 测试录音
arecord -D hw:0,0 -f S16_LE -r 16000 -c 1 -d 5 test.wav
```

### 问题 2：语音识别失败

**现象：**
```
[ERROR] 语音识别失败
```

**解决：**
```bash
# 检查模型文件
ls -la /data/zipformer/model/*.rknn

# 检查程序
ls -la /data/zipformer/rknn_zipformer_demo

# 手动测试
cd /data/zipformer
./rknn_zipformer_demo model/encoder.rknn model/decoder.rknn model/joiner.rknn model/test.wav
```

### 问题 3：播放失败

**现象：**
```
[ERROR] 播放失败
```

**解决：**
```bash
# 检查扬声器
aplay -l

# 安装播放工具
apt-get install alsa-utils

# 测试播放
aplay /data/zipformer/model/test.wav
```
