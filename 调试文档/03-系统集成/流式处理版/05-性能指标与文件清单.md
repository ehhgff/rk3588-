# 05-性能指标与文件清单

## 5.1 性能指标

### 5.1.1 服务启动时间

| 服务 | 启动时间 | 说明 |
|------|---------|------|
| RAG服务 | ~2秒 | RKNN NPU + 科室索引 |
| LLM服务 | ~3-4秒 | Qwen3-0.6B RKLLM模型加载 |
| TTS服务 | ~1-2秒 | MeloTTS RKNN模型加载 |
| **总启动** | **~6-8秒** | 全流程 |

---

### 5.1.2 端到端响应时间

| 步骤 | 耗时 | 说明 |
|------|------|------|
| VAD检测 | 实时 | 边录边检测 |
| 语音识别 | ~1.4s | Zipformer流式识别 |
| RAG检索 | 0.3-1.1s | 科室优化后 |
| LLM生成 | ~1.5s | Qwen3-0.6B优化后 |
| TTS合成 | ~2-3s | MeloTTS RKNN |
| **总耗时** | **~5-7s** | 完整流程 |

**时间分解图**:
```
语音输入
    │
    ▼
┌─────────────┐  ~1.4s
│ VAD + ASR   │  实时检测 + 流式识别
└──────┬──────┘
       │
       ▼
┌─────────────┐  0.3-1.1s
│ RAG检索     │  科室优化版
└──────┬──────┘
       │
       ▼
┌─────────────┐  ~1.5s
│ LLM生成     │  Qwen3-0.6B
└──────┬──────┘
       │
       ▼
┌─────────────┐  ~2-3s
│ TTS合成     │  MeloTTS RKNN
└──────┬──────┘
       │
       ▼
语音输出
```

---

### 5.1.3 资源占用

| 服务 | 内存占用 | 说明 |
|------|---------|------|
| RAG服务 | ~800MB | 含RKNN模型 |
| LLM服务 | ~1GB | Qwen3-0.6B W8A8 |
| TTS服务 | ~300MB | MeloTTS RKNN |
| **总计** | **~2.1GB** | 建议4GB内存 |

**内存使用分布**:
```
总内存: 2.1GB
┌─────────────────────────────────────┐
│ LLM服务     ████████████████  1.0GB │
│ RAG服务     ████████████      0.8GB │
│ TTS服务     ████              0.3GB │
└─────────────────────────────────────┘
```

---

### 5.1.4 版本性能对比

| 对比项 | RAG科室优化版 | 流式处理版 | 提升 |
|--------|--------------|-----------|------|
| **语音识别方式** | 离线文件识别 | 流式实时识别 | 延迟降低50% |
| **VAD检测** | 无 | Silero VAD | 自动触发 |
| **服务架构** | 直接调用 | Unix Socket服务化 | 响应更快 |
| **LLM模型** | InternVL3-1B | Qwen3-0.6B | 更小更快 |
| **TTS引擎** | 原版TTS | MeloTTS RKNN | NPU加速 |
| **端到端延迟** | ~7.5-9.5s | **~5-7s** | **提升26%** |
| **启动时间** | ~6-7s | **~6-8s** | 相当 |
| **内存占用** | ~2.3GB | **~2.1GB** | **降低9%** |
