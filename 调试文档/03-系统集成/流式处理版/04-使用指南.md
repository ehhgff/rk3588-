# 04-使用指南

## 4.1 环境要求

### 4.1.1 硬件要求
| 项目 | 要求 | 说明 |
|------|------|------|
| **内存** | 4GB+ | 实际占用~2.1GB |
| **存储** | 2GB+ Swap | 用于模型加载 |
| **音频设备** | USB麦克风 + USB音响 | card 0录音，card 1播放 |
| **NPU** | RK3588 | 用于RKNN加速 |

### 4.1.2 软件依赖
| 依赖 | 版本 | 说明 |
|------|------|------|
| Python | 3.10+ | 运行环境 |
| PyTorch | 2.1.0 | aarch64版本 |
| onnxruntime | 1.16.3 | aarch64版本 |
| RKNN Runtime | - | NPU推理 |

## 4.2 快速开始

### 4.2.1 启动所有服务

```bash
# 一键启动所有服务
cd /userdata/voice_assistant
./start_all_services_v2.sh
```

1. 设置Swap (2GB)
2. 清理旧服务

### 4.2.2 运行语音助手

```bash
cd /home/ubuntu/桌面/ai/voice_assistant
python3 streaming_vad.py
```

**使用流程**:
1. 程序启动后，自动开始监听
2. 对着麦克风说话（连续5帧人声触发录音）
3. 说完后等待0.7秒，自动停止录音
4. 系统自动进行语音识别 → RAG检索 → LLM生成 → TTS合成
5. 听到回复音频

## 4.4 常见问题排查

### 4.4.1 服务启动失败

**排查步骤**:
```bash
# 1. 检查日志
tail -f /tmp/rag_optimized_server.log
tail -f /tmp/qwen3.log
tail -f /tmp/melotts_service.log

# 2. 检查Socket文件是否存在
ls -la /tmp/*.sock

# 3. 检查进程是否在运行
ps aux | grep -E "rag|qwen|melotts"

# 4. 检查内存使用
free -h
```

---

### 4.4.2 音频无法播放

**排查步骤**:
```bash
# 1. 检查音频设备
aplay -l
arecord -l

# 2. 测试播放
speaker-test -D plughw:1,0 -c 1 -t wav

# 3. 检查音量
amixer -c 1 get PCM

# 4. 设置音量
amixer -c 1 set PCM 30%
```

---

### 4.4.3 识别效果差

**排查步骤**:
```bash
# 1. 检查麦克风
arecord -D plughw:0,0 -f S16_LE -r 16000 -c 1 -d 5 /tmp/test.wav
aplay -D plughw:1,0 /tmp/test.wav

# 2. 调整VAD阈值
# 编辑 streaming_vad.py
threshold = 0.5  # 降低阈值，提高灵敏度
threshold = 0.9  # 提高阈值，减少误触发

# 3. 调整连续帧数
SPEECH_FRAMES_TO_START = 3  # 减少帧数，更容易触发
SPEECH_FRAMES_TO_START = 7  # 增加帧数，减少误触发
```

---

### 4.4.4 TTS无声音

**排查步骤**:
```bash
# 1. 检查音频文件
file /tmp/test_tts.wav

# 2. 检查文件大小
ls -lh /tmp/test_tts.wav

# 3. 使用正确的播放参数
aplay -D plughw:1,0 -r 44100 -f FLOAT_LE -c 1 /tmp/test_tts.wav

# 4. 检查TTS服务日志
tail -f /tmp/melotts_service.log
```

## 4.5 高级配置

### 4.5.1 修改VAD参数

编辑 `streaming_vad.py`:
```python
# VAD阈值 (0.0-1.0)
# 越低越灵敏，越高越严格
threshold = 0.7

# 连续语音帧数触发录音
SPEECH_FRAMES_TO_START = 5

# 静音帧数停止录音 (帧数 = 秒数 / 0.03)
SILENCE_FRAMES_THRESHOLD = 23  # 0.7秒
```

---

### 4.5.2 修改TTS参数

编辑 `streaming_vad.py`:
```python
# 语速 (0.5-2.0)
# < 1.0 慢速，> 1.0 快速
speed = 0.6

# 音量 (0-100%)
# 在 setup_audio() 函数中修改
subprocess.run(["amixer", "-c", "1", "set", "PCM", "40%"], capture_output=True)
```

---
