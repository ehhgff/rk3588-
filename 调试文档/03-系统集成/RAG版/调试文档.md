# RK3588医疗咨询RAG系统 - 完整部署文档

## 一、项目概述

本项目实现了一个面向RK3588平台的医疗咨询检索增强生成(RAG)系统，支持中文医疗问答，采用混合检索策略结合向量检索和关键词匹配，针对边缘设备进行了深度优化。

### 核心特性
- **混合检索**: FAISS向量检索 + BM25关键词检索 + RRF融合
- **D2嵌入策略**: 使用title+question组合生成语义嵌入
- **意图识别**: 基于医学术语的科室预测
- **过滤机制**: 反义词冲突检测 + 人群匹配过滤
- **边缘优化**: ONNX Runtime推理 + INT8量化

## 四、核心算法

### 4.1 混合检索流程
```python
def hybrid_search(query, k=3):
    # 1. 意图识别
    dept = predict_department(query)
    
    # 2. 向量检索 (FAISS)
    vec_scores, vec_indices = vector_index.search(query_vector, k*6)
    
    # 3. 关键词检索 (BM25)
    bm25_scores = bm25.get_scores(tokenize(query))
    bm25_top_k = top_k_indices(bm25_scores, k*6)
    
    # 4. RRF融合
    combined = {}
    for rank, idx in enumerate(vec_indices):
        combined[idx] += 0.6 / (rank + 60)
    for rank, idx in enumerate(bm25_top_k):
        combined[idx] += 0.4 / (rank + 60)
    
    # 5. 意图增强
    if dept:
        for idx in combined:
            if departments[idx] == dept:
                combined[idx] *= 1.2
    
    # 6. 过滤冲突结果
    filtered = filter_conflicts(combined, query)
    
    return top_k(filtered, k)
```

### 4.2 过滤机制

#### 反义词冲突检测
```python
ANTONYM_PAIRS = [
    ('高血压', '低血压'),
    ('高血糖', '低血糖'),
    ('甲亢', '甲减'),
    ('失眠', '嗜睡'),
    ('便秘', '腹泻'),
]

def check_antonym_conflict(query_terms, result_text):
    for term in query_terms:
        if any(antonym in result_text for antonym in term.antonyms):
            return True  # 存在冲突，排除结果
```

#### 人群匹配过滤
```python
SPECIAL_POPULATIONS = {
    '孕妇': ['孕妇', '怀孕', '孕期', '产妇'],
    '儿童': ['儿童', '孩子', '宝宝', '婴儿'],
}

def filter_population(query_pop, result_pop):
    # 普通患者查询不应返回特殊人群结果
    if not query_pop and result_pop:
        return False  # 排除
    # 特定人群查询应匹配相应人群
    if query_pop and result_pop:
        return any(p in result_pop for p in query_pop)
    return True
```


```
解决:
```

```
现象: 无法解析JSON文件
原因: 文件格式为JSONL而非JSON数组
解决: 
  # 改为JSON数组格式
  data = [json.loads(line) for line in f]
```

```
现象: 科室分布严重不平衡
原因: 分层采样逻辑错误
解决: 
  # 实现正确的分层采样
  for dept in departments:
      dept_samples = min(len(samples), samples_per_dept)
      selected.extend(random.sample(samples, dept_samples))
```

## 九、总结

本项目成功实现了RK3588平台上的医疗咨询RAG系统，主要成果：

1. **高准确率**: SBERT-768达到87.5%科室准确率

- 实现离线部署支持无网络环境
